# Frontend

React + TypeScript + Vite.

## Structure

- `src/app` — application entry and composition.
- `src/pages` — screens.
- `src/components` — reusable UI components.
- `src/api` — HTTP requests.
- `src/types` — shared TypeScript types.
- `src/styles` — global styles.

## Run

```powershell
npm install
npm run dev
```
